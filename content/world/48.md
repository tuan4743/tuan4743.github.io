> **载体** 方舟出厂技术文件,第 12 版　｜　**完整性** 100%

**第一条**　本数据库收录自 T−06:11 至本舰出厂期间的全部可回收碎片,来源包括原始广播、各代中继版本、以及至少四个已灭绝文明的自留档案。

　　**本舰为文明级方舟:一整个文明即一艘方舟。**舰下设区,区下设组,组由个体锚点集合而成。
　　著录项"载体"栏按此三级标注。凡称"方舟 N 号"者,一律为误录。

```text
本舰编成

   长夜方舟 ................ 一整个文明 = 一艘方舟
    |
    +-- 第三区 ............ 在册 118,409 枚
    |    |
    |    +-- 第 11 组 ..... 在册 4,100 枚
    |    |    |
    |    |    +-- 锚点 .... 一个体 = 一锚点(非阿贝尔拓扑孤子)
    |    |    +-- 锚点
    |    |    +-- ... ..... 首批亮起 12 枚 = 校准组
    |    |
    |    +-- 第 12 组 ...
    |
    +-- 第七区 ...
```

**第二条**　碎片按回收顺序存放,**不按时间存放**。顺序需乘员自行建立。

**第三条**　每份碎片前的著录项(源事件、载体、完整性、距离、泡壁抵达、剩余)由本数据库统一添加。碎片原有格式一律保留,不作改写。

**第五条**　本数据库不提供结论。碎片与碎片之间的空白,由乘员自行补全。
　　——这是设计,不是缺陷。

**第七条**　若某段记忆与档案不符,以档案为准。
　　若两份档案互相矛盾,以早的那一份为准。
　　若有第三份档案声称前两份均为伪造,调阅它,但不要停在那里。

**第九条**　碎片中出现"我们不知道"之处,原样保留,不得修订。那不是缺漏,那是源头最后 32 分钟里说得最多的一句话。

**第十一条**　每艘方舟出厂时预置一个**方舟总控 AI** 的子代理。其职责只有一项:在乘员身份发生漂移时执行记忆校准。
　　它不解释这些碎片。它只负责让你还能读懂它们。

**第十三条**　本数据库无编目者署名。
　　编目者是所有把话说完的人。
